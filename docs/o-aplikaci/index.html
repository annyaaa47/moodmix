O aplikaci a soukromí

Moodmix je nástroj na moodboardy. Obrázky se samy seskupí podle vzhledu a ukážou se jako graf. Je zdarma, bez registrace a bez reklam.

Tvoje data zůstávají u tebe

Obrázky, videa, skupiny, poznámky i prezentace se ukládají jen do tvého prohlížeče na tomhle zařízení. Na žádný server se neposílají a nikdo jiný je nevidí.

Proto je neuvidíš na jiném počítači ani v jiném prohlížeči. Když vymažeš data prohlížeče (historie, soubory cookie a data webů), moodboardy zmizí.

Zálohuj si je: v levém panelu „Zálohovat tento moodboard“ stáhne ZIP se vším a „Obnovit ze zálohy“ ho kdykoli vrátí jako nový moodboard.

AI běží v prohlížeči

Třídění podle vzhledu dělá model CLIP přímo ve tvém počítači. Při prvním nahrání se jednou stáhne (asi 150 MB) z Hugging Face a jeho běhové soubory z jsDelivr, pak je uložený v prohlížeči. Obrázky se nikam neposílají.

Kdy aplikace mluví s jinými službami

Jen když danou funkci použiješ:

  • Pinterest: import veřejné nástěnky. Odkaz a stažení pinů jdou přes server aplikace na Pinterest (v ukázkové verzi bez serveru se seznam pinů čte přímo z Pinterestu a obrázky jdou přes bezplatnou službu wsrv.nl).
  • Openverse: „Doplnit podobné z internetu“. Hledá se podle slov popisujících styl (ne podle samotného obrázku), náhledy jdou přes server aplikace.
  • Google Fonts: návrhy písem v detailu a v prezentaci.
  • Hugging Face a jsDelivr: stažení AI modelu (viz výše).

Počítání návštěv

Kolik lidí aplikaci otevřelo, počítá Cloudflare Web Analytics. Nepoužívá cookies ani jiné ukládání v prohlížeči, nesleduje tě napříč weby a nevidí nic z tvých moodboardů. Proto tu není lišta se souhlasem.
